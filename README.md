# ONE

App personal de Carlos Torres para aprender sin leer: un juego infinito de preguntas sin teclado (swipe, tap, ordenar), con memoria, repetición espaciada y dificultad adaptativa. Una pantalla, un botón.

Proyecto independiente de CT Advisory: repo propio, base de datos propia. Se reutilizan piezas genéricas de aquel proyecto (capa de modelos con control de coste, motor determinista y cuestionario de Wealth, herramientas de auditoría visual, CI con Postgres), nunca nada de negocio.

## Estado (8-sep-2026)

- Conversación de origen con ChatGPT, solo referencia: `docs/2026-09-08-conversacion-chatgpt.md`.
- Decisiones: uso personal; MENTE primero, CUERPO mínimo en el sprint 2; preguntas verificadas por un segundo modelo gratis de otra familia; PWA instalable desde Safari sobre Node + Postgres en el VPS.
