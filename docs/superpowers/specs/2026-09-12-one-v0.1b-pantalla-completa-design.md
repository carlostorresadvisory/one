## Tesis espacial

Cada vista es una columna de tres zonas, siempre a pantalla completa (100dvh, sin scroll):

```
┌──────────────────────────┐
│ cabecera fija (← ONE 🔥) │  contexto, nunca cambia
│ progreso ▬▬▬▬▬░░░░░░     │
│                          │
│   ZONA MEDIA (flex: 1)   │  lo que se lee: la tarjeta, centrada verticalmente
│   ┌──────────────────┐   │  en el espacio que quede, nunca pegada arriba
│   │ Área · nivel     │   │
│   │ Enunciado        │   │
│   │ (opciones/filas) │   │
│   └──────────────────┘   │
│                          │
│ ZONA DE ACCIÓN (abajo)   │  lo que se toca: donde llega el pulgar
│ Confianza [Baja|Media|Alta]
│ [  FALSO  ] [ VERDADERO ]│  (solo vf; test4/ordenar/error se tocan en la tarjeta)
│ ────────── safe-area ────│
└──────────────────────────┘
```

Reglas de la zona de acción:
- Está anclada al borde inferior (`margin-top: auto` dentro de la vista + `padding-bottom: env(safe-area-inset-bottom)`), con alto mínimo estable para que la tarjeta no salte entre preguntas.
- Ritmo: espacio generoso entre zona media y zona de acción (≥ 24 px), apretado dentro de cada grupo (8-12 px).
- En **vf**: los botones FALSO / VERDADERO salen de la tarjeta y van a la zona de acción, 56 px de alto, ocupando el ancho. La tarjeta lleva en su borde inferior una **pista de deslizamiento**: dos chevrones `‹` y `›` en texto suave a los lados y, centrada, la frase "Desliza la tarjeta o toca" en 12 px. La frase se muestra las primeras 5 preguntas vf del dispositivo (contador en localStorage `one.pistaSwipe`); los chevrones se quedan siempre. Al arrastrar, el chevrón del lado hacia el que se arrastra se tiñe de ko/ok como ya hace la tarjeta.
- En **test4 / ordenar / error**: la zona de acción solo lleva la fila de confianza; la tarjeta crece hacia el centro.
- **Confianza**: una fila, etiqueta "Confianza" a la izquierda en texto suave (14 px, peso 500) y el control segmentado a la derecha ocupando el resto (alto 44 px). Segmento activo: relleno cian, texto oscuro. Se oculta al responder, como ahora.
