# ONE v0.1c "Mazo vertical" — Plan de implementación

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Partida y repaso como mazo vertical de tarjetas a pantalla completa (pasar/volver, confianza editable dentro de la tarjeta, sin scroll, botones "Preguntar a", repaso estilo TikTok).

**Architecture:** PWA vanilla sin build (`index.html` + `estilos.css` + `app.js` ES module + `motor.js` puro). El motor gana `cambiarConfianza` y dos campos en el delta. La UI sustituye el flujo "una pregunta a la vez" por un array `mazo` de huecos navegable con gesto vertical; la vista `resumen` reutiliza la misma tarjeta en modo lectura.

**Tech Stack:** HTML/CSS/JS ES2022, `node --test` (motor), Playwright (`npx playwright test`, capturas en `docs/capturas/`), GitHub Pages en `/one/` (rutas relativas), service worker `sw.js`.

**Spec:** `docs/superpowers/specs/2026-09-12-one-v0.1c-mazo-vertical-design.md` (leerla entera antes de cada tarea; es el contrato).

```js
/** Corrige la confianza de una respuesta YA registrada (spec v0.1c §3.1). No es una
 * respuesta nueva: no toca combo, nivelPartida, racha, recuperadas ni misión. */
export function cambiarConfianza(estado, pregunta, delta, confianzaNueva, hoy) {
  if (!CONFIANZAS.includes(confianzaNueva) || confianzaNueva === delta.confianza) {
    return { estado, delta };
  }
  const nuevo = { ...estado, tarjetas: { ...estado.tarjetas }, confianza: { ...estado.confianza }, historial: [...estado.historial] };
  const { correcta, xpBase, cajaAntes, prioridadAntes } = delta;
  const anterior = delta.confianza;

  // XP
  const xpNuevo = correcta ? (confianzaNueva === 'alta' ? Math.round(xpBase * 1.5) : xpBase) : 0;
  nuevo.xp = estado.xp + xpNuevo - delta.xp;

  // Tarjeta
  const tarjeta = { ...nuevo.tarjetas[pregunta.id] };
  if (correcta) {
    if (confianzaNueva === 'baja') { tarjeta.caja = cajaAntes; tarjeta.fragil = true; }
    else { tarjeta.caja = Math.min(cajaAntes + 1, 4); tarjeta.fragil = false; }
    tarjeta.proximo = sumarDias(hoy, INTERVALOS[tarjeta.caja]);
  } else {
    tarjeta.prioridad = confianzaNueva === 'alta' ? 2 : Math.max(1, prioridadAntes);
  }
  nuevo.tarjetas[pregunta.id] = tarjeta;

  // Calibración
  const resta = (k, ok) => { nuevo.confianza[k] = Math.max(0, nuevo.confianza[k] - 1); if (correcta) nuevo.confianza[ok] = Math.max(0, nuevo.confianza[ok] - 1); };
  const suma = (k, ok) => { nuevo.confianza[k] += 1; if (correcta) nuevo.confianza[ok] += 1; };
  if (anterior === 'alta') resta('altas', 'altasOk');
  if (anterior === 'baja') resta('bajas', 'bajasOk');
  if (confianzaNueva === 'alta') suma('altas', 'altasOk');
  if (confianzaNueva === 'baja') suma('bajas', 'bajasOk');

  // Historial: última entrada de esta pregunta
  for (let i = nuevo.historial.length - 1; i >= 0; i--) {
    if (nuevo.historial[i].id === pregunta.id) { nuevo.historial[i] = { ...nuevo.historial[i], confianza: confianzaNueva }; break; }
  }

  return { estado: nuevo, delta: { ...delta, xp: xpNuevo, confianza: confianzaNueva, fragil: tarjeta.fragil } };
}
```
