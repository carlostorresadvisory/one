# ONE v0.2b1 — Plan: servidor de generación verificada (`servidor/`)

> **For agentic workers:** REQUIRED SUB-SKILL: superpowers:subagent-driven-development. Tareas con checkbox.

**Goal:** Un servicio Node sin dependencias, desplegable en Docker detrás de Caddy, que mantiene un colchón de preguntas **verificadas** (hecho + utilidad + nivel por modelo distinto, explicación corta y visual verificados) y las sirve al móvil por una API con token.

**Architecture:** `servidor/index.js` (HTTP nativo, rutas, token, rate limit, CORS) → `servidor/cola.js` (cola única en serie, prioridad urgente/fondo, escrituras atómicas) → `servidor/generacion.js` (generar → verificar en una llamada → `validarPregunta` → `resolverPregunta`), con `llamar` inyectable para tests. Prompts compartidos con la CLI extraídos a `tools/prompts-preguntas.js`.

**Tech Stack:** Node 22 ES modules sin dependencias; `node:test`; Docker (`node:22-alpine`, `caddy:2-alpine`).

**Spec:** `docs/superpowers/specs/2026-09-14-one-v0.2-generacion-y-repaso-design.md` §0, §3 y §5.

## Global Constraints

- Español en todo; sin dependencias; módulos ES; ficheros en `servidor/` y `tools/prompts-preguntas.js`; tests en `tests/servidor*.test.js`. **No tocar** `app.js`, `motor.js`, `index.html`, `estilos.css`, `sw.js` ni `tests/e2e.spec.js` (otro plan los tiene abiertos).
- **La verificación nunca se salta**: nada entra en el colchón sin (a) verificación por modelo distinto del generador con `correcta && unica && inequivoca && cumpleUtilidad && confianza >= 0.7`, (b) `validarPregunta` de `tools/validar-banco.js`, (c) `resolverPregunta` de `tools/visualizar.js`.
- `OPENROUTER_API_KEY` solo se lee dentro de `tools/openrouter.js` vía `process.env`; nunca se registra, devuelve ni imprime. Los tests no hacen red: `llamar` falso inyectado. Ninguna llamada real a la API en este plan salvo la prueba final que lanza el controlador.
- Solo modelos `:free` salvo `PERMITIR_PAGO=1` con `TOPE_EUR_DIA` (acumulado del día en `datos-servidor/llamadas.log`, mismo mecanismo que `llamar({permitirPago, topeEur, rutaLog})`).
- Un solo escritor de disco (la cola); escrituras atómicas (temporal + `rename`). Errores HTTP sin trazas ni rutas internas.
- Sin `git push`; `git add` de rutas explícitas; commits pequeños en español.
